# Glossary

> **TL;DR:** Terminology reference ensuring consistent language across all products. Contains usage terms covering spelling, capitalization, punctuation, and preferred/disallowed usage for in-product copy and conversational AI. New products add terms here — if a term conflicts with an existing definition, create a conflict entry for resolution.

## Purpose

Terminology definitions. This glossary serves as the single source of truth for terminology used across components, themes, copy guidelines, and product UIs.

## Entry Structure

Each entry includes: Term, Definition, Context of Use, Examples, Synonyms (if allowed), Disallowed Terms, Notes.

## Rules

- No invented terms or definitions
- Use consistently across all files and products
- Conflicts → flag for resolution
- Synonyms must be explicitly allowed; otherwise disallowed
- Undefined terms → do not define speculatively

## General Writing Usage

| Term | Guidance |
|------|----------|
| abort | Do not use in reference to human beings. Use "stop", "end", or "cancel". |
| above / below | Use only for physical space or screen descriptions. For document orientation, use "previous"/"preceding" (not "above") and "following"/"later" (not "below"). |
| action | Use "operation" or "API operation" for implementation-neutral content. "Action" is OK in permissions policy context. |
| activate / deactivate | Use for setting up or disassociating account details. For features, use "enable"/"disable". For settings, use "turn on"/"turn off". |
| ad hoc | Avoid. Use "one-time" instead. |
| affect / effect | "Affect" (verb) means to influence. "Effect" (noun) means result. Do not confuse. |
| allow / deny | OK for permissions. Avoid in direct reference to the customer — rewrite to focus on the customer's perspective. |
| allowlist / denylist | One word each. Do not use "whitelist" or "blacklist". |
| and/or | Avoid. |
| app / application | Use "app" for mobile software, "application" for all other uses. |
| appear / display / open | Messages "appear". Windows/pages/applications "open". "Display" requires a definite object. |
| as | Do not use "as" to mean "because" — it is frequently ambiguous. |
| as well as | Avoid. Use "in addition to" or "and". |
| backend / frontend | One word each (adjective and noun). Not "back end", "back-end", "front end", or "front-end". |
| backup (n.) / back up (v.) | One word as noun, two words as verb. |
| be able to | Avoid. Use "can" instead. |
| best | Do not use superlatives. Exception: "best practices" is OK. |
| Boolean | Capitalize unless referring to a specific code element that uses lowercase. |
| browse | Use for scanning information. For navigation, use "see" or "navigate to". |
| build (n., v.) | As verb: compiling and linking code. As noun: a compiled version of a program. |
| by using / using | Use "by using" or "that use" instead of "using" to avoid ambiguity. |
| choose / select | Preferred over "click" (device-independent language). |

## AI and Conversational Interface Usage

| Term | Guidance |
|------|----------|
| agent | Can refer to human support agent or AI assistant. Be explicit on first use ("human support agent", "AI agent"). |
| AI | Stands for "artificial intelligence". Do not spell out after first mention. |
| AI-generated | Hyphenate as adjective. Two words as verb. Do not use "generative AI-generated" or "AI-gen". |
| algorithm / model | Algorithms create models. Do not use interchangeably. |
| answer / response | AI provides a "response" (preferred) or "answer". Use "response" for AI replies. |
| ask / request | A user "asks" a question or makes a "request". "Request" is preferred. |
| assistant | Use for AI services providing assistance through a chat interface. On first mention, use "generative AI assistant" or "AI assistant". |
| bot | Do not use when describing chat-based AI. Use "assistant", "model", or "AI". |
| generative AI | The approved term for referring to the AI experience. Do not abbreviate as "gen AI". |
| generative AI assistant | The approved term for introducing and referring to the AI on first mention. |
| model | A trained AI system. Do not use interchangeably with "algorithm". |
| submit | Use as the label or reference term when a user makes a choice, query, or request. |
| support agent | Use "support agent". Do not use "representative" or "human support". |

## Punctuation and Formatting Usage

| Term | Guidance |
|------|----------|
| ampersand (&) | Do not use in running text. |
| ellipsis (...) | Do not use in UI copy or instructional text. |
| exclamation point | Do not use. |
| e.g. / i.e. / etc. | Do not use. Write out "for example", "that is", or rephrase. |
| bold | Use only as adjective ("characters in bold type"). Do not use "boldface". |
| bookmark | Preferred over "favorite" for a saved link. |
| 24/7, 24/7/365 | Do not use. Use "all day" or "every day". |
| 3D | Do not spell out. Do not use "3-D". |
